================================================================
  ★ 중요: 인터넷 없이 동작합니다 (오프라인 대응)
================================================================
예전에는 Tailwind·폰트 등을 인터넷에서 받아 썼기 때문에,
학교 망이 외부 주소를 막거나 인터넷이 끊기면 수업 중에
화면이 통째로 깨졌습니다. 지금은 그럴 일이 없습니다.

 · 화면 스타일(Tailwind)과 폭죽 효과 → index.html 안에 넣었습니다
 · 한글 웹폰트 → fonts 폴더에 넣었습니다

[ 배포할 때 함께 올릴 것 ]
   index.html      ← 반드시
   fonts 폴더      ← 글꼴 (없으면 기본 시스템 글꼴로 나옵니다. 동작에는 지장 없음)
   images 폴더     ← 그림 (없으면 내장 SVG 그림이 나옵니다)

※ index.html 하나만 있어도 게임은 정상 작동합니다.
   fonts·images 는 '더 예쁘게' 만드는 선택 사항입니다.
